— 02

Scope. Two tiers. No refusals.

SKILL.md § Scope

Special tier — rich treatment

  • landing — marketing, sales, product launch
  • portfolio — work showcase, hire-me, personal site
  • Type-specific anatomy + Next.js skeleton
  • Per-vibe section archetypes
  • Full Tier 1/2/3 anti-slop audit
  • Evidence-backed (12 marketing landings analyzed)

Generic tier — universal craft

  • blog, about, pricing, contact, coming-soon
  • error-page (404 / 500), legal, dashboard, admin, e-commerce
  • Any custom --type string
  • Generic anatomy + generic Next.js skeleton
  • Sections driven by Page-Purpose Exercise (no fixed template)
  • Universal anti-slop subset (Applicability Matrix filter)
  • Best-effort craft for app-surface types (evidence base partial)

Universal toolkit applies to both tiers — vibe lock, palette, typography, custom icons, 2D illustrations, visual effects, motion intensity. No refusals; suggestions for companion skills live in § Beyond.

— 05

Anti-slop. Tier 1 = auto-fail. Tier 2 = caution. Tier 3 = compensable.

anti-slop-rules.md
Tier 1 — Must fix

Auto-fail patterns

  • DM Sans + Space Grotesk Google Fonts pair
  • AI purple/blue gradient hero with gradient text highlight
  • lucide-react / @heroicons / icon library imports
  • Two equal-weight CTAs in hero
  • h-screen utility class
  • 3-column equal feature card grid
  • Tailwind utility density > 200 in HTML
  • Generic SaaS CTAs ("Get Started", "Sign In")
  • AI-generated 3D model as hero subject
  • OrbitControls in landing/portfolio
Tier 2 — Caution

Compositional drift

  • Generic browser-mockup as right-half of split hero
  • Friendly bullet checkbox reassurance row
  • Round fake stats (10K+, 99.99%)
  • AI-generated cute illustration as hero
  • Centered hero + centered H1 at high variance
  • 3D model used purely as decoration
  • Style mixing across 2D illustrations
  • Generic fade-up motion on every element
  • ease-in-out 0.3s as universal duration
Tier 3 — Compensable

Cohesion ≥ 8/10 saves

  • Inter as body when paired with distinctive display
  • AI cliché phrases in non-load-bearing copy
  • Generic startup names in placeholders (Acme, Globex)
  • Title Case On Every Header

Allowed only IF visual craft cohesion ≥ 8/10 (see commitment audit). Override path: user requests twice + reason logged.

— 06

Eight mandates. Non-negotiable.

SKILL.md § Hard Rules

Mandates are doctrine — what the skill MUST and MUST NOT do. Anti-slop tiers above are audit patterns the skill greps for. Mandates are the why behind tier-1 patterns.

— 01

NO emoji — anywhere

Not in copy, headings, or as icons. Use a custom SVG instead.

— 02

NO icon libraries

Lucide, Heroicons, Phosphor, Tabler, Font Awesome, Material, react-icons — all forbidden.

— 03

NO AI slop defaults

Inter alone, purple/blue gradient hero, two equal CTAs, "Elevate / Seamless / Unleash" copy, fabricated metrics (use — metric to confirm placeholder instead), meta-label headers ("SECTION 01"), hero filler text ("Scroll to explore").

— 04

NO 3D models as hero

Static render → PNG OK. Real-time GLB forbidden (user-product GLB needs override).

— 05

3D = effects only

Phase 5 = shaders, particles, atmosphere. CSS first; WebGL only when CSS can't.

— 06

Always propose effect layer

Every site gets the proposal. User accepts or declines. Default = decline.

— 07

Vibe before pixels

Never write code or generate assets before vibe + palette + typography are locked.

— 08

Type-aware where it matters

Landing / portfolio get rich type-specific anatomy + per-vibe archetypes. All other types use generic anatomy + skeleton. Phase 8 audit filters rules per --type tier.

— 09

Diversify each run

Same skill, different output each time. Macrostructure must differ from last 3 entries in .perfect-ui/log.json. Vibe / dials / motion personality should differ from last entry (soft warning).

— 07

In practice. Four real flows.

README.md § Examples

"Design a landing page for a new specialty coffee subscription service targeting home-brewing enthusiasts in Japan. Vibe should feel editorial and warm."

  1. Phase 0 detects --new (no URL provided)
  2. Phase 0.5 detects landing from "landing page"
  3. Phase 1 → inline brainstorm protocol locks vibe = editorial + agrarian (wildcard), 3 inspirations confirmed
  4. Phase 2 → palette cream #F5F1E8 + ink + dusk-rose accent · Migra + GT Sectra · asymmetric editorial · 3D declined
  5. Phase 3 → 8 custom SVG icons designed (nav-mark, brewing-step icons, social marks)
  6. Phase 4 → silkscreen-style poster hero illustration via text-to-image with style control
  7. Phase 6-8 → inline plan + implement + Tier 1/2/3 audit; ships

Editorial coffee landing with custom assets, vibe-paired type, zero AI slop. No 3D, no icon library, no purple gradient anywhere.

"Redesign this portfolio: https://my-old-site.com — I want it to feel more elegant and let my work speak. Currently has too many flashy hover effects."

  1. Phase 0 detects --redesign (URL provided)
  2. Audit per redesign-audit-checklist.md — keep portfolio cover photo + custom monogram; kill hover-effect overload, skill-bar percentages, "Hi I'm passionate" opener
  3. Phase 0.5 detects portfolio
  4. Phase 1-2 → elegant vibe locked · PP Neue Montreal display · off-white palette · atmospheric spatial
  5. Phase 3-5 → minimal icon set (5 icons) · editorial environmental portrait · 3D logo accent approved
  6. Phase 6-8 → Plan with app/work/[slug] case study route → audit catches "Welcome to my portfolio" leftover copy → fixes → ships

Restrained portfolio that lets the work breathe. Atmospheric, not flashy. Audit-caught copy leftover prevented a slop-shipped redesign.

"Design a blog landing for a typography studio's writing. Editorial vibe, long-form serif."

  1. Phase 0 detects --new
  2. Phase 0.5 detects blog keyword → generic tier
  3. Phase 1 → generic brief with Page-Purpose Exercise (job = inform, marketing-intent = true)
  4. Phase 2 → palette cream + ink + ochre accent · PP Editorial Old + Söhne · asymmetric editorial · motion 1-2/3
  5. Phase 3 → 3 custom SVG icons (tag-glyph, link-arrow, social mark)
  6. Phase 4 → letter-form silkscreen hero accent
  7. Phase 6 → generic plan: nav + hero + article-list + footer (driven by page-purpose, not template)
  8. Phase 8 → audit runs [universal] + [marketing-only] subset; [landing/portfolio-only] rules skipped — passes

Editorial blog landing with the same craft discipline as a landing page. Section stack picked from generic anatomy, not templated.

"Design a dashboard for a self-hosted analytics tool. Brutalist vibe, dense info, dark mode."

Evidence-base disclosure (logged at Phase 0.5): skill's evidence base (12 marketing landings analyzed) does NOT cover dashboard / admin / e-commerce / app-surface patterns directly. Universal craft toolkit still applies. Output quality is best-effort, not evidence-backed.
  1. Phase 0 detects --new
  2. Phase 0.5 detects dashboard keyword → generic tier + disclosure logged
  3. Phase 1 → generic brief (data displayed, user role, page-purpose = display data, marketing-intent = false)
  4. Phase 2 → brutalist vibe · Söhne Mono + Söhne Breit · hi-contrast + electric-yellow accent · motion 1/3 CSS-only
  5. Phase 3 → 6 custom icons (data-source markers, filter glyphs, sort-direction, refresh-state)
  6. Phase 4 → schematic illustration for empty-states
  7. Phase 6 → app-shell (sidebar + topbar) + filter-bar + data-grid + empty-state — no hero, no CTA, purpose-driven
  8. Phase 8 → audit runs [universal] rules only; marketing-only rules (two equal CTAs, gradient hero, feature grid) skipped

Dashboard with vibe lock, custom icons, motion discipline — without false-positive audit warnings about marketing patterns that don't apply.

— 08

Getting started. Activate by asking.

README.md

Trigger phrases

design a landing page for [product] design my portfolio design my pricing page build a blog landing create an about page design a dashboard for [tool] design a 404 / coming-soon page redesign this site → [URL]

The skill auto-detects mode (new vs redesign) and type. Landing / portfolio route to special tier; any other type routes to generic tier with universal craft toolkit. No refusals — app-surface types (dashboard / admin / e-commerce) get an evidence-base disclosure and proceed.

Flags

--type   any value   (special: landing / portfolio · generic: everything else — asks if unspecified)
--new / --redesign   (auto-detects from URL/screenshot)
--no-3d   (skip Phase 5 entirely)
--stack   nextjs | astro | vanilla   (default: nextjs)
