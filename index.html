Scope. What's in. What's not.

SKILL.md § Scope

Handles

  • Landing pages — marketing, sales, product launch
  • Portfolios — work showcase, hire-me, personal site
  • Vibe-driven visual direction (palette, type, spatial)
  • Custom SVG icon sets (zero emoji, zero icon libraries)
  • 2D illustrations: AI-generated, SVG, static 3D render → PNG
  • Visual effects: CSS atmosphere, shaders, particles
  • Vibe-scaled motion (CSS → Framer Motion → Lenis → GSAP)
  • Next.js + Tailwind + shadcn implementation

Refuses

  • Full apps — use ck:frontend-development
  • Dashboards, admin panels — use ck:frontend-development
  • E-commerce stores — use ck:shopify
  • SaaS internals, app surfaces
  • AI-generated 3D models as hero subject
  • Backend APIs, auth, payment integration
  • Blog sites (deferred — not yet supported)

— 04

Anti-slop. Tier 1 = auto-fail. Tier 2 = caution. Tier 3 = compensable.

anti-slop-rules.md
Tier 1 — Must fix

Auto-fail patterns

  • DM Sans + Space Grotesk Google Fonts pair
  • AI purple/blue gradient hero with gradient text highlight
  • lucide-react / @heroicons / icon library imports
  • Two equal-weight CTAs in hero
  • h-screen utility class
  • 3-column equal feature card grid
  • Tailwind utility density > 200 in HTML
  • Generic SaaS CTAs ("Get Started", "Sign In")
  • AI-generated 3D model as hero subject
  • OrbitControls in landing/portfolio
Tier 2 — Caution

Compositional drift

  • Generic browser-mockup as right-half of split hero
  • Friendly bullet checkbox reassurance row
  • Round fake stats (10K+, 99.99%)
  • AI-generated cute illustration as hero
  • Centered hero + centered H1 at high variance
  • 3D model used purely as decoration
  • Style mixing across 2D illustrations
  • Generic fade-up motion on every element
  • ease-in-out 0.3s as universal duration
Tier 3 — Compensable

Cohesion ≥ 8/10 saves

  • Inter as body when paired with distinctive display
  • AI cliché phrases in non-load-bearing copy
  • Generic startup names in placeholders (Acme, Globex)
  • Title Case On Every Header

Allowed only IF visual craft cohesion ≥ 8/10 (see commitment audit). Override path: user requests twice + reason logged.
